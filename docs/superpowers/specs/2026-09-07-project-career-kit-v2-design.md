# `project-career-kit` V2 设计规格

## 目标

将后端项目中的可核验实现转化为中文求职材料，帮助使用者把项目写进简历、在面试中讲清核心链路，并挑选关键代码深入学习。生成文件不是技术审计报告，也不展示内部证据台账。

## 固定产物

生成目录为 `career-kit/`，每轮只新增以下四个 Markdown 文件：

```text
career-kit/
|- 简历素材.md
|- 面试逐字稿.md
|- 项目流程图.md
`- 证据索引.md
```

旧版本生成的英文文件名保留不动。本版本不新增第五个辅助文件。

## 面向使用者的输出

### 简历素材

`简历素材.md` 只呈现适合求职表达的项目背景、技术、链路、亮点、职责、指标和风险边界。它不包含源码路径、扫描过程、编号或证据表。

### 面试逐字稿

`面试逐字稿.md` 的 60 秒和 3 分钟内容必须能直接朗读。核心链路、难点或排查等关键章节可在正文后附一条简短的 `源码定位（备查）`，使用相对路径和短行范围，例如：

```markdown
> 源码定位（备查）：`app/api/tasks.py:5-11`（路由与 service 调用）；`app/services/task_service.py:1-3`（业务处理与返回）。
```

定位用于使用者复习和应对追问，不是口播正文，不得逐句罗列或使用绝对路径。已验证的项目定位直接用项目语言表达，不在口播中叙述 README、配置或源码的交叉验证过程。

### 项目流程图

`项目流程图.md` 必须至少包含一个 fenced Mermaid `flowchart`，直接表达最小已验证链路。图内采用简洁中文节点；节点和边只能描述代码可验证的静态关系，不能把路由注册描述为真实请求调度，或凭方法名、注释虚构数据库、队列、异步投递或运行时成功。若图写顶层初始化顺序，必须按实际代码顺序排列；跨模块的注册或关联不能被硬画成虚假的先后调用关系。

图后增加“学习导航”，为 3 至 5 个核心节点提供相对路径与短行范围，方便使用者沿流程阅读实现：

```markdown
## 学习导航
- 应用创建与路由注册：`app/main.py:1-6`
- 任务路由与 service 绑定：`app/api/tasks.py:5-11`
- 业务处理与可见返回：`app/services/task_service.py:1-3`
```

不再使用 `%% evidence:`、HTML 注释、编号或其他隐藏审计元数据。

### 证据索引

为保持四文件约定，`证据索引.md` 保留文件名，但内容改为极简的输入确认清单，只能包含两个二级标题：

```markdown
# 项目材料输入与待确认项：<项目/模块名>

## 输入与默认值
- 目标岗位：...
- 语言与格式：...
- 篇幅：...
- 已提供的项目说明：...

## 待用户确认
- 本人参与范围：...
- 个人职责：...
- 业务背景与项目目标：...
- 指标与结果：...
```

该文件不包含扫描记录、结论清单、来源等级、确定性、源码定位、冲突与未知、映射表或编号化证据。运行期未知仍在相关简历、面试稿或流程图上下文中简洁写为 `【未知】`，不叙述本次扫描、已读或已检查范围；个人信息缺口写为 `【待确认】`。业务背景与项目目标在输入清单中是请用户补充或确认的内容，不改变求职材料中的未知事实标记。

## 内部真实性控制

生成期间仍建立仅存在于本轮工作上下文的临时事实清单，记录已读来源、短行范围、确定性和边界。每个项目事实、核心关系、字面值、分支、范围否定和未知项都要由该清单直接支持；不能支持的内容必须删除、收窄或标为 `【未知】` / `【待确认】`。

README 仅作为背景线索，必须与源码或配置交叉验证。没有用户确认时，材料以“项目”或“代码”为主语，不写“我设计”或“我实现”。

## 实施边界

- 保持四个中文文件名、只读安全扫描、`【未知】` / `【待确认】` 的语义区分以及项目清单脚本行为。
- 移除交付文件中的证据编号、来源等级、扫描记录、映射表和 Mermaid 隐藏注释。
- 不修改 `agents/openai.yaml`、`scripts/project_inventory.py` 或已经生成给用户的材料。
- 源码定位只能指向本次读取的非敏感相对源码路径与短行范围，且只服务于面试学习与流程导航。

## 验证

回归测试必须确认：

- 输出仍恰好是四个中文文件；
- `证据索引.md` 只有“输入与默认值”“待用户确认”两个二级标题；
- 四份模板和紧凑示例不出现 HTML evidence 注释、`%% evidence:`、编号化证据、来源等级、映射表或扫描记录；
- 面试稿关键章节有可选的“源码定位（备查）”，但 60 秒和 3 分钟概述不放路径；
- 流程图包含干净 Mermaid 图和图后的“学习导航”；
- README 定位仍需源码或配置交叉验证，且未确认个人归属不被写成第一人称事实。
